## Service Tracker
    Service Tracker — это SPA-дашборд для мониторинга доступности HTTP-сервисов. Приложение позволяет добавлять сервисы, периодически проверять их доступность и отслеживать статус, время ответа и историю проверок.

## Стек технологий
    Фреймворк: Svelte 5 + SvelteKit (режим CSR, ssr = false)

    Язык: TypeScript

    Стилизация: Чистый CSS

    Хранение данных: localStorage
